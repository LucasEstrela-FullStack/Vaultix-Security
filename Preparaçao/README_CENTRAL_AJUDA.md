# Central de Ajuda e Acolhimento

## Funcionalidade
A **Central de Ajuda e Acolhimento** foi implementada na terceira aba do aplicativo (`app/(tabs)/help.tsx`).

## O que foi gerado
- `src/features/help-center/screens/HelpCenterScreen.tsx`: Tela que permite ao usuário solicitar ajuda com opções de categorias (Ameaça, Assédio, Cyberbullying) e um campo de relato opcional.

## Princípios Respeitados (Acolhimento / Anonimato)
- **Anonimato:** O usuário pode relatar a situação sem precisar informar dados pessoais.
- **Minimização de Dados:** Os dados solicitados são opcionais e a plataforma foi desenhada para priorizar o contato com instituições seguras.
- **Canais Oficiais:** A tela apresenta atalhos rápidos para canais de proteção como o Disque 100 e o CVV (188).
