# Quiz Consciente

## Funcionalidade
O **Quiz Consciente** foi implementado na segunda aba do aplicativo (`app/(tabs)/quiz.tsx`).

## O que foi gerado
- `src/features/quiz/screens/QuizScreen.tsx`: Tela contendo a lógica de perguntas interativas sobre segurança digital.

## Princípios Respeitados (Educativo / Prevenção)
- **Conteúdo Fictício:** As perguntas são baseadas em cenários simulados (ex: sextorsão) para ensinar boas práticas sem expor casos reais.
- **Feedback Educativo:** A cada resposta, o usuário recebe um feedback explicando o motivo e sugerindo ações seguras, como bloquear contatos suspeitos.
- **Segurança de Dados:** O módulo não coleta nenhuma informação sensível do usuário para o uso da funcionalidade.
